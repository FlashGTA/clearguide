# ClearGuide 공공서비스형 데모

소개 페이지: `index.html`  
GitHub Pages를 활성화하면 `https://<owner>.github.io/<repository>/`에서 이 페이지를 제출 링크로 사용할 수 있습니다. 이 저장소에는 `main`의 `demo/` 변경을 자동 배포하는 Pages workflow가 포함되어 있습니다.

로그인·개인정보·실제 민원 제출 없이 ClearGuide의 핵심 여정을 재현하는 fixture입니다.

## 실행

1. `pages/start.html`을 브라우저에서 엽니다.
2. `ClearGuide 데모 시작`을 누릅니다.
3. 단계별 안내에 따라 `다음`과 실제 입력/선택 동작을 수행합니다.
4. 마지막 페이지에서 완료 화면을 확인합니다.

또는 시작 화면에서 목표를 입력하고 `AI 안내 여정 찾기`를 누르면 Goal Router가 등록된 업무 여정을 추천합니다. 현재 fixture에서는 재현 가능한 키워드 fallback을 사용하며, 실제 AI 모델은 `ClearGuideGoalRouter({ analyzer })` 주입 지점에 연결합니다.

이 데모는 Player SDK를 사용하므로 확장 프로그램을 설치하지 않아도 됩니다. 실제 공공서비스 연결 전에 다음을 검증합니다.

- 여러 페이지 사이의 세션 복구
- 사용자 확인이 필요한 입력 단계
- 요소가 없을 때의 재시도·중단 처리
- 완료까지의 단계 진행

## 대표 여정

“공공 생활지원 서비스 신청 안내”라는 가상 업무를 다음 6단계로 재현합니다.

1. 서비스 이용 목적 확인
2. 대상 서비스 선택
3. 신청자 유형 선택
4. 필요한 서류 안내 확인
5. 신청 전 확인
6. 안내 완료

실제 기관 서비스에 연결할 때는 이 workflow를 기관별 Guide Template JSON으로 교체합니다. 민감정보 입력·제출·결제는 데모 범위에 포함하지 않습니다.
