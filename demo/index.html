왜 필요한가

정보는 있는데,
다음에 뭘 해야 할지 모르겠습니다.

공공 웹서비스는 메뉴와 용어가 어렵고 입력 단계도 많습니다. 화면이 바뀌거나 오류가 나면 사용자는 어디까지 했는지조차 잊기 쉽습니다.

눌러야 할 곳을 찾기 어렵습니다

긴 안내문과 많은 버튼 사이에서 지금 필요한 요소를 골라야 합니다.

중간에 다시 처음으로 돌아갑니다

페이지 이동·새로고침·오류 뒤에도 진행 상태를 이어갈 방법이 필요합니다.

답변만으로는 업무가 끝나지 않습니다

링크를 알려주는 데서 멈추지 않고 실제 화면의 다음 행동까지 보여줘야 합니다.

어떻게 돕나

사용자는 목표만 말하면 됩니다.
나머지는 한 단계씩 따라갑니다.

01 · 목표

무엇을 하려고 하시나요?

입력한 목표를 등록된 업무 여정 후보와 연결합니다.

02 · 화면 확인

지금 어디에 있나요?

현재 화면에서 다음 단계에 필요한 요소를 찾습니다.

03 · 한 단계 안내

지금 누를 곳을 보여줍니다

버튼·입력창·메뉴를 강조하고 쉬운 말로 설명합니다.

04 · 이어가기

멈춰도 다시 시작합니다

페이지 이동과 오류를 기억하고 재시도·중단·재개를 돕습니다.

AI는 어디까지

AI가 길을 찾고,
사람이 마지막 결정을 합니다.

민원 제출·결제·민감정보 입력은 자동으로 처리하지 않습니다. AI의 추천은 검증된 업무 여정과 사용자의 확인을 거칩니다.

AI가 도와주는 일

목표 분류현재 단계 찾기다음 행동 추천오류 설명

사용자의 목표와 비민감 UI 정보를 바탕으로 등록된 업무 여정과 복구 방법을 추천합니다.

사용자가 결정하는 일

진행 확인민감정보 보호임의 실행 차단안전한 종료

현재 데모는 재현 가능한 workflow와 키워드 fallback으로 동작합니다. 실제 AI 모델은 analyzer 모듈에 연결할 수 있습니다.
