# ClearGuide Studio Privacy Policy

Last updated: 2026-10-05

ClearGuide Studio is a browser extension for creating and previewing step-by-step web guides.

## Data handled by the extension

When you create or import a guide, ClearGuide Studio may store the following information locally in your browser:

- guide name and author-written guide text
- target website domain and URL patterns
- DOM selectors and element labels used to locate guide targets
- guide step configuration
- local guide progress while previewing a guide

## Storage

Extension guide data is stored in `chrome.storage.local` on your device.

The current extension does not use analytics, advertising, tracking SDKs, or a ClearGuide cloud account.

The current extension code does not transmit stored guide data to ClearGuide servers.

## Site access

ClearGuide Studio requests access only to website origins that you choose for guide authoring or preview. Site access is used to inject the bundled ClearGuide authoring/preview code into those approved sites.

## Export and import

You can export guide templates as JSON files and import them later. Exported files are controlled by you and are not automatically uploaded anywhere by ClearGuide Studio.

## Deletion

You can delete individual guides or clear locally stored guide data from the extension.

You can also remove site permissions from Chrome's extension settings.

## Third-party services

The current extension does not send guide data to third-party services.

A website that separately embeds the ClearGuide Player SDK is responsible for its own site privacy practices and any guide data it chooses to load.

## Changes

This policy will be updated if ClearGuide Studio begins collecting or transmitting data in a new way. Store disclosures and this policy must remain consistent with the released extension.

## Contact

For privacy or security questions, use the GitHub issue tracker for this repository.
